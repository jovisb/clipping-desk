# Clipping desk

Home page and privacy policy for Clipping desk, a personal self-hosted tool that cuts short clips from long videos and posts the ones its owner approves to the owner's own channels.

Served with GitHub Pages:

- Home page: https://jovisb.github.io/clipping-desk/
- Privacy policy: https://jovisb.github.io/clipping-desk/privacy.html

Questions about the privacy policy can be opened as an issue in this repository.
